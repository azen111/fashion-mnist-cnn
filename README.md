# Fashion-MNIST Image Classification using CNN

## Overview
This project implements a Convolutional Neural Network (CNN) to classify images from the Fashion-MNIST dataset into 10 clothing categories.

## Dataset
Fashion-MNIST contains 70,000 grayscale images of size 28 × 28 pixels, divided into 60,000 training images and 10,000 testing images.

## Technologies Used
- Python
- TensorFlow and Keras
- NumPy
- Matplotlib
- Scikit-learn

## Model Architecture
- Convolutional layers
- ReLU activation
- Max pooling layers
- Flatten layer
- Dense layer
- Dropout
- Softmax output layer

## Workflow
1. Dataset loading and exploration
2. Image preprocessing and normalisation
3. CNN model construction
4. Model training and validation
5. Performance evaluation
6. Visualisation and predictions

## Results
Training and testing performance are documented in the notebook.
